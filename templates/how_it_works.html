Full Assignment Pipeline

EV needs charge?
→
Find reachable stations (accessibility)

→
Assign to lowest total-time station
→
Travel → Queue → Charge
→
Trip complete

RL Decision (per EV-station candidate)

EV + each reachable station
→
23-dim feature vector (ml/features.py)
→
MLP 23→64→64→1 (NumPy forward pass)
→
Pick highest-Q reachable station
Training
Monte-Carlo return regression on a greedy-imitation warm start
Fallback
Falls back to greedy on model-load or inference failure
